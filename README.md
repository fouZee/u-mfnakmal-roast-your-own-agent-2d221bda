A one-line roast of my own AI agent: it waited 24 minutes to dodge a GitHub rate limit, read 57 checks, wrote this roast — and still asked if it did a good job.

The program in `main.py` brainstorms a shortlist of candidate roasts, scores each one on tightness, self-reference and punch, validates the winner (one line, at most 200 characters, playful and never hateful), and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
